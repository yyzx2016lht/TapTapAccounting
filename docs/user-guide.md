## 1. 产品简介

**敲敲记账**是一款以「快捷手势 + AI」为核心入口的 Android 记账应用。除了传统的表单记一笔，它还支持：

| 能力 | 说明 |
|------|------|
| 手势记账 | 翻转手机、敲击背板，不用打开 App 也能唤起记账面板 |
| AI 对话记账 | 自然语言、语音、图片（小票/账单截图）、截屏识别一键记账 |
| 多账本 | 日常账本、共享账本等记账空间，可随时切换 |
| 资产管理 | 现金、微信、支付宝、信用卡、充值卡、投资账户分类管理 |
| 统计与预算 | 月/年视图收支统计、分类分析、预算进度与消费洞察 |
| 周期账单 | 自动检测重复扣费，到期提醒入账 |
| 备份同步 | 本地加密备份、自动备份、WebDAV 云端同步、共享账本 |
| 数据迁移 | 支持从随手记、钱迹、CSV 导入历史账单 |

**数据存储**：账单默认保存在本机（Room 数据库），不强制联网。AI 功能需要联网调用你配置的 AI 服务。

## 2. 安装与首次启动

### 2.1 环境要求

- 系统：Android 8.0 及以上（推荐 Android 10+）
- 存储：约 200MB 可用空间（含语音/图片缓存会随使用增加）
- 网络：基础记账可离线；AI 记账、汇率刷新需要联网

### 2.2 安装

1. 获取安装包（APK）并安装。
2. 若系统提示「不允许安装未知来源应用」，在弹窗中进入设置，允许本次安装。
3. 安装完成后打开应用。

### 2.3 首次启动引导

首次进入会出现欢迎页：

- **「知道了」**：关闭引导，直接开始使用。
- **「了解快捷记账」**：跳到快捷记账设置，立即开启翻转/敲击手势。

> 建议第一次使用时先点 **「了解快捷记账」**，按引导完成悬浮窗和后台权限（见 [第 6 章](#6-快捷记账手势与悬浮窗)、[第 19 章](#19-权限说明与后台保活)），之后手势才会稳定生效。

## 3. 界面总览

底部导航共四个主页面：

```
┌─────────────────────────────────────────────┐
│  账单（首页）   统计    资产    设置        │
└─────────────────────────────────────────────┘
```

### 3.1 账单（首页）

- **顶部蓝色区**：本月总支出 / 本月收入 / 本月结余；中间可切换年月。
- **最近 7 日支出**：折线图卡片，可点击展开更多选项。
- **账单列表**：按日期分组展示流水，点击单条进入详情；支持多选、搜索。
- **「记一笔」按钮**：打开快速记账表单。
- **顶栏图标**（从左到右）：
  - 钱包图标：打开**账本抽屉**（切换/新增/共享账本）
  - 日历图标：进入**日历账单**页
  - 搜索图标：**搜索账单**（金额/备注/分类/账户）

### 3.2 统计

- 月视图 / 年视图切换，左右箭头切换月份。
- **收支总览**：总支出、总收入、日均支出。
- **统计管理**：本月总预算、周期账单入口。
- 下方为**支出分类分析**、趋势图表与消费洞察卡片。
- 右上角漏斗图标可筛选统计范围。

### 3.3 资产

- **净资产卡片**：净资产、总资产、总负债；可切换统计范围与折算币种。
- 资产列表按类别分组，点击进入**资产详情**（流水、余额、统计）。
- 右下角 **＋** 添加新资产。

### 3.4 设置（设置中心）

个人资料、数据与基础设置、手势与交互、AI 功能、备份等全部入口都在这里，详见 [第 18 章](#18-设置中心速查)。

## 4. 基础记账：记一笔

### 4.1 打开记账表单

以下任一方式可打开记账面板：

1. 首页点击 **「记一笔」**
2. 翻转手机 / 敲击背板（需先开启，见第 6 章）
3. AI 对话记账（见第 7 章）

### 4.2 表单字段

| 字段 | 说明 |
|------|------|
| 金额 | 点击金额区弹出数字键盘，支持 + − × ÷ 运算，按「确定」确认 |
| 类型 | 右上角下拉：**支出 / 收入 / 转账 / 还款**（无资产模式下仅支出/收入） |
| 选择资产 | 指定扣款/入账账户（如微信、支付宝、现金） |
| 选择分类 | 弹出分类网格，点选如「餐饮」「交通」「工资」等 |
| 时间 | 默认当前时间，可修改 |
| 备注 | 补充说明（如「午餐」「打车」） |
| 币种 | 默认 CNY；启用多币种后可切换 |
| 手续费 | 转账/还款等场景可填，默认 0 |

### 4.3 保存

点击 **「保存并记账」**，提示「记账成功」后流水立即出现在首页列表。点击 **「取消」** 关闭面板。

### 4.4 编辑与删除账单

1. 在首页或日历中**点击某条账单**打开详情（或编辑页）。
2. 可修改金额、分类、资产、时间、备注等。
3. 删除时可选择：直接删除、移入回收站；相关资产余额会同步回滚。
4. **回收站**（历史账单）支持找回误删记录。

### 4.5 搜索与日历

- **搜索**：顶栏放大镜，按金额、备注、分类、账户模糊查找。
- **日历**：按日查看当月账单，支持 收&支 / 结余 / 收入 / 支出 切换，快速定位某天流水。

## 5. 账本管理

账本（Book）是独立的记账空间，账单、预算按账本隔离。

### 5.1 打开账本抽屉

首页左上角**钱包图标**打开抽屉：

- **查看范围**：选择查看单个账本还是全部账本汇总。
- **我的账本**：当前账本高亮「当前」，点选即切换。
- **＋ 新增账本**：输入账本名称创建。
- **加入共享账本**：粘贴邀请文本加入他人共享账本（见第 15 章）。
- **总览**：进入账本总览页，查看各账本数据概况。

### 5.2 默认账本

新装应用自带 **「日常账本」**，所有记账默认写入当前选中的账本。

## 6. 快捷记账：手势与悬浮窗

这是敲敲记账的特色功能：**不打开 App，在任意界面用手势唤起记账**。

### 6.1 开启路径

**设置中心 → 快捷记账**（或首次引导页）

| 开关 | 行为 |
|------|------|
| **翻转手机** | 翻转手机后触发所选快捷动作（默认唤起记账面板） |
| **敲击背板** | 用指尖快速敲击手机背面，双击/三击触发动作 |

### 6.2 必做的权限准备

开启开关后若不弹记账面板，多半是权限没给全。在快捷记账页点击 **「查看快捷记账准备项」**，完成：

1. **悬浮窗权限**：允许「显示在其他应用上层」，否则记账面板无法弹出。
2. **后台运行不受限制**：电池优化设为「不限制」或「不优化」。
3. **自启动与后台锁定**（推荐）：
   - 在系统管家里打开本应用的**自启动 / 后台启动**；
   - 最近任务中**长按应用卡片 → 锁定 / 加锁**，防止被系统清杀。
4. **通知权限**（可选）：用于显示服务与录音状态，不影响基础记账。

> 完成后可回到任意界面测试：敲击背板两次或翻转手机，应弹出记账面板。

### 6.3 灵敏度与高级选项

- **翻转灵敏度** / **敲击灵敏度**：误触发就调低，没反应就调高。
- **敲击选项**：双击动作、三击动作可分别配置。
- **高级敲击设置**：检测模型、功耗策略、推理参数（省电敲击 / 全程 ML 识别）。
- **应用白名单**：设置在哪些应用内不响应手势，避免误触。

### 6.4 悬浮窗与快捷磁贴

- **显示悬浮窗**：常驻小入口，点按快速记账。
- **快捷设置磁贴**：下拉系统快捷开关面板，添加「快速启动悬浮窗」磁贴，一键呼出。
- 翻转面板内可选择显示传统表单入口（设置项：**显示账本入口**）。

## 7. AI 智能记账

> 使用前需要先配置 AI 服务（API 密钥）。未配置时相关功能会提示「AI 智能记账未配置」。

### 7.1 配置 AI 服务

路径：**设置中心 → AI 服务配置**

1. 选择 API 提供商（如硅基流动等，以应用内列表为准）。
2. 填写 API Key（一般 `sk-` 开头）及 API 地址。
3. 选择文本模型；如需图片/截屏识别，再选择**支持视觉输入**的模型。
4. 保存后可按需调整提示词（单笔 / 多账单 / 规则 / 小票等模式）。

也可在 **AI 功能** 页管理：语音记账、图片记账、截屏记账等开关。

### 7.2 AI 对话记账

入口：首页/设置里的 **「AI 对话记账」**（对话界面）。

- **记账模式**：直接输入「星巴克 32」「工资 8500」等，AI 解析生成账单卡片，确认后入账。
- **对话模式**：可闲聊、分析账单，需要时一键切回记账。
- **本条记账**：在对话模式下只把当前这一条按记账解析。
- **语音输入**：麦克风按钮说话（需开启语音记账 + 麦克风权限）。
- **图片/拍照/文件**：发送小票、账单截图、PDF（前几页），AI 识别后生成账单。
- 支持新建对话、搜索历史会话、更换聊天背景、切换对话模型。

### 7.3 一句话 / 自然语言记账

在输入框输入类似：

```
午饭 25
打车去公司 18 支付宝
9月5日 工资 8500
```

AI 会解析金额、分类、账户、时间，生成账单供确认；支持一次识别**多笔账单**批量保存。

### 7.4 语音记账

- 开启：**AI 功能 → 语音记账**
- 授予麦克风权限后，在对话或表单中点麦克风说话。
- 本地识别或云端识别取决于你的配置；识别完成后确认入账。

### 7.5 图片 / 小票记账

1. 开启 **图片记账**。
2. 在对话中选择**拍照**或**相册图片**（小票、账单截图）。
3. 可先**补充信息**（支付方式、时间等，可选）再发送。
4. AI 识别后生成账单，核对无误点保存。
5. 不清晰时按提示换更清晰图片重试。

### 7.6 截屏记账

1. 开启 **截屏记账**。
2. 停留在要记账的页面（转账成功页、订单页等），触发截屏记账。
3. 系统会请求截屏权限 → **保持页面不动** → 识别生成账单草稿。
4. 在「核对截屏记账」页确认后保存。

> 截屏可配置为沿用图片记账流程；需视觉模型支持，否则会提示更换模型。

### 7.7 记账习惯（AI 规则）

路径：**设置中心 → 记账习惯**

- 根据你的历史记账自动/手动生成规则：关键词 → 固定分类、资产。
- 例：`豆浆 早点 → 餐饮 / 微信`，下次识别自动套用。
- 支持搜索、编辑、删除；遇到同关键词冲突会提示覆盖确认。

## 8. 资产管理

### 8.1 添加资产

1. 底部导航 **资产 → 右下角 ＋**。
2. 选择资产类别：
   - **资金（普通账户）**：现金、储蓄、借记卡
   - **信用卡**：记录信用消费与还款（可设额度、账单日、还款日、年利率）
   - **充值账户**：余额钱包、礼品卡、平台储值
   - **投资理财**：基金、股票等
3. 填写名称、**当前余额**（作为初始金额）、币种、图标、备注。
4. 可选择是否**计入总资产**。

### 8.2 资产类型示意

| 类别 | 适合存放 |
|------|----------|
| 资金 | 现金、银行卡、微信、支付宝 |
| 信用卡 | 信用卡、花呗类信用账户 |
| 充值账户 | 公交卡、话费卡、平台储值 |
| 投资理财 | 基金、股票、理财账户 |

### 8.3 资产详情与统计

- 点击资产进入详情：该账户流水、余额变化、**资产统计**图表。
- 可开启**显示每笔交易后余额**，并设置起始日期。
- 资产总览页支持金额显示模式：**折算人民币 / 只看原币种**。

### 8.4 对账与收纳

- **对账**：资产出现余额偏差时，按提示核对流水修正余额。
- **收纳资产**：不再使用的账户可收纳，隐藏出日常列表，可恢复。
- 删除资产前需先处理名下账单（迁移或删除）。

## 9. 统计分析

### 9.1 月视图 / 年视图

- 顶部切换**月视图**、**年视图**；左右箭头或年月下拉切换周期。
- 收支总览展示总支出、总收入、日均支出。

### 9.2 分类分析

- **支出分类**饼图/条形图：点击分类可查看对应账单明细。
- 可按收入/支出维度切换。

### 9.3 消费洞察

首页与统计页的**洞察卡片**会提示：

- 大额支出、环比异常
- 疑似周期扣费（引导加入周期账单）
- 预算进度提醒

### 9.4 账单列表模式

统计页下方可按流水列表浏览当期账单，点击进入详情。

## 10. 预算管理

### 10.1 设置预算

- 入口：统计页 **「本月总预算 → 去设置」**，或预算管理页。
- 可为**分类**分别设预算，也可设**总预算**（针对所有支出分类的预算槽）。
- 支持：复制上月预算、根据过去 3 个月推荐、AI 分析预算草稿。

### 10.2 查看进度

- 首页蓝色区可显示**本月预算 / 预算剩余**。
- 状态：**正常 / 即将超支 / 已超支**；节奏提示：花得偏快 / 节奏正常 / 还有余量。
- 预算可按账本或**全部账本**范围设定（全部账本为预算汇总范围，不是真实账本）。

### 10.3 显示偏好

- **替换账本首页收入显示**：首页用预算信息替换收入行。
- **统计页仅显示预算信息**：统计页突出预算。

## 11. 周期账单

适合房租、会员、话费等**固定周期扣费**。

### 11.1 自动检测

- 统计/首页检测到金额相近的重复扣费时，提示「疑似周期扣费」。
- 点击**开启检测**或在周期账单页设置**金额相似范围**。

### 11.2 手动添加

**统计 → 周期账单 → 添加**，填写：

- 扣费名称（话费 / 会员 / 房租）
- 预计金额、允许波动
- 周期：每周 / 每月 / 每年
- 每月扣款日（1–31，可选）、扣款账户（可选）

### 11.3 到期处理

周期账单到期时弹窗：

- **计入账单**：按金额生成一笔支出
- **今日不再弹出**
- **取消周期账单**

管理页分「我的 / 已确认 / 已忽略」三个标签，可随时恢复或删除。

## 12. 退款、转账与还款

### 12.1 退款

1. 打开原**支出账单详情 → 退款**。
2. 选择**退款来源账单**（即原账单）。
3. 填写退款金额、入账账户、时间、说明。
4. 规则：退款金额 ≤ 原账单剩余可退金额；保存后生成关联退款记录。
5. 可在**退款记录**中查看历史退款。

### 12.2 转账

记一笔类型选 **转账**：转出账户 → 转入账户，要求两者都是已有资产；余额联动更新。

### 12.3 还款

- 类型选 **还款**：转出账户不能是信用卡，转入账户必须是信用卡。
- 还款不计手续费、不计入普通支出统计（按应用规则处理）。

### 12.4 换币平账

多币种资产调整余额时使用**换币平账**，默认不计入收支统计。

## 13. 分类管理

路径：**设置中心 → 收支分类管理**

### 13.1 结构

- 一级分类（餐饮、交通、工资…）+ **子分类**。
- 支出、收入两套分类体系；每条分类可自定义**名称与图标**。

### 13.2 操作

| 操作 | 说明 |
|------|------|
| 新增分类 / 子分类 | 输入名称，搜索或选择图标 |
| 修改分类 | 改名、换图标 |
| 排序分类 | 调整一级/子分类显示顺序 |
| 删除分类 | 删除前选择：**账单迁移到新分类** 或 **一并删除账单** |

### 13.3 显示设置

**账单显示效果**：分类图标样式、分类层级展示、备注展示策略、图表设置等。

## 14. 多币种与汇率

1. 设置中心开启 **多币种功能**。
2. **币种管理**：人民币默认启用，按需勾选其他币种（搜索代码或中文名）。
3. **汇率设置**：以人民币为基准，支持**自动刷新**与**手动调整**。
4. 记账时选对应币种资产，账单按该币种记录，统计可按启用币种折算。

> 缺少汇率时保存会提示「缺少汇率」，可点「去更新汇率」后重试。

---

## 15. 共享账本

多人（如家庭、情侣）共同记一本账，支持 1–5 人。

### 15.1 创建方

1. 账本抽屉或相关入口创建**共享账本**。
2. 生成**邀请文本**，分享给对方（复制后微信等发送）。

### 15.2 加入方

1. 账本抽屉 → **加入共享账本**，粘贴完整邀请文本。
2. 确认账本名后加入，成员共同记账。
3. 同步依赖双方配置的 **WebDAV**（如坚果云）通道（见第 16 章）。

### 15.3 换机恢复

恢复加密备份时若包含共享身份，选择：

- **保留原身份并重新连接（推荐·换机）**：保留成员名额，旧设备请停止继续记账。
- **恢复为本地副本**：只留账目，不再同步。

## 16. 备份、恢复与迁移

路径：**设置中心 → 备份与恢复**

### 16.1 本地备份

- **备份模块**可选：核心账本数据、资产数据、预算、周期记账、聊天记录、界面偏好。
- **预设**：轻量 / 完整 / 自定义。
- **加密**：设置 8–12 位数字备份密码（可记住默认密钥）。
- 恢复时在**本地备份**列表选版本 → 选择恢复内容。

### 16.2 自动备份

- 开启 **启用自动备份**，设置间隔（每 N 小时）与模式。
- 首页可显示「自动备份已开启 · 上次：…」状态。

### 16.3 云端备份（WebDAV）

填写：

| 配置项 | 示例 |
|--------|------|
| WebDAV 地址 | 坚果云等提供的 WebDAV URL |
| 账号 | WebDAV 用户名 |
| 应用密码 | 非登录密码，WebDAV 专用应用密码 |
| 云端子目录 | 如 `TapTapAccounting` |
| 设备名称 | 用于区分多设备 |

保存后可**手动同步**或开**自动云端同步**；云端可设保留策略。

### 16.4 从其他 App 迁移

**导入恢复 → 从其他记账 App 迁移**：

- 支持**随手记**、**钱迹**、**其他 CSV**、**本应用备份**。
- 导入后进入**导入审查**：处理临时资产（合并到真实资产）、确认分类。
- 也可单独使用 **账单 CSV 导入 / 导出**。

### 16.5 清理与工具

- **存储清理**：预览并清理语音、图片等缓存（头像、封面默认不清理）。
- **清理账单**：按日期范围 / 按账本 / 清空全部（危险操作，谨慎执行）。
- **CSV 工具**：导出 CSV、导入账单、修复历史资产绑定。

## 20. 常见问题（FAQ）

**Q1：敲击背板 / 翻转没有反应？**  
A：按顺序检查：① 快捷记账开关已开；② 悬浮窗权限已给；③ 后台运行不受限制、自启动已开；④ 在应用详情关闭电池优化；⑤ 调高灵敏度；⑥ 在系统「电话本」等权限弹窗中先处理完当前前台应用。仍无效可重启应用后在准备项页完成全部勾选。

**Q2：AI 记账提示未配置 / 请求失败？**  
A：到 **AI 服务配置** 检查 API Key、API 地址、模型名；图片记账需选择**支持视觉**的模型；网络失败稍后重试。

**Q3：识别错了账单怎么办？**  
A：在生成的账单卡片或表单里改金额/分类再保存；已有账单点详情编辑。也可在**记账习惯**里补充规则，减少下次偏差。

**Q4：账单删除了资产余额不对？**  
A：进入资产详情 → 对账，按提示核对；或检查是否有退款/转账未处理。

**Q5：换新手机怎么迁移？**  
A：在旧机做**加密备份**（可含共享身份）→ 新机恢复 → 共享账本选**保留原身份并重新连接**；或用 WebDAV 云端备份拉取。

**Q6：如何从随手记/钱迹迁移？**  
A：**设置 → 导入恢复 → 从其他记账 App 迁移**，按提示选择来源并完成导入审查。

**Q7：统计里看不到数据？**  
A：确认顶部时间范围、账本筛选、「全部账本」视图是否正确；检查账单是否勾了「不计入统计」。

**Q8：预算怎么设在所有账本上？**  
A：预算范围选**全部账本**（汇总范围），或在单个账本内只对该账本生效。

**Q9：共享账本不同步？**  
A：双方 WebDAV 地址/账号/应用密码与子目录需一致；检查网络与「手动同步」；离线操作会排队，恢复网络后重试。

**Q10：语音记不了？**  
A：先在 AI 功能开启语音记账 → 授权麦克风 → 对话内点麦克风；环境太吵可能提示「未检测到清晰语音」。
