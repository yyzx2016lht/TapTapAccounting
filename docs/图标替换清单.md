# 图标替换清单

本清单由 `python tools/classify-icons.py` 自动生成，用于区分「钱迹原创美术作品」与「第三方品牌标识」。

## 分类规则

- **A 通用分类图标**：`category.json` / `default_category.json` 中的语义图标（餐饮、交通、律师费…）。与钱迹分类体系绑定，**必须替换**。
- **B 通用资产图标**：`assets.json` 中表示「钱的形态」的图标（现金、银行卡、公积金…）。虽在资产库中，但同为钱迹原创美术作品，**必须替换**。
- **D 源码硬编码默认图标**：`AssetIconDefaults` 等处的兜底图标，**必须替换**。
- **C 第三方品牌标识**：银行 logo（`ic_bank_*`）、支付平台、加密货币 token 等。这些是各品牌方的商标资产，钱迹亦非原创，**可保留**（在 App 内标示资金来源属指示性合理使用）。
- **C?**：规则未命中，需人工确认。
